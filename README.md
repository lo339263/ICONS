# ICONS Colour Laboratory

Generate **ICONS** from CIELAB or XYZ. The result includes the ICONS name, an sRGB swatch, and CIELAB, XYZ and sUCS coordinates.

## Web app

Open [docs/index.html](docs/index.html) in a browser. No installation or server is required; calculations run locally.

Choose CIELAB or XYZ, enter three coordinates, select **D65** or **Custom** reference white, and click **Generate ICONS**.

D65 uses the CIE 1964 10-degree white point `[94.810, 100, 107.305]`. XYZ and custom white points use the Yw=100 scale. The app uses fixed defaults: La=64, Yb=20 and average surround.

## ICONS

ICONS is generated by `generate_u_name(appearance)` and stored in `ColorStimulus.u_name`:

```text
JJJCCChhh + NCS hue + depth description + Gaussian colour name
```

J, C and h are floored and padded to three digits. Spaces are removed from the text components. ICONS describes appearance; the object's UUID provides its unique identifier.

## Python

Requires Python 3.10 or later.

```bash
python -m pip install -r requirements.txt
python tests/test_core.py
```

The example prompts for XYZ or Lab and prints ICONS. To use the same white point as the web app:

```bash
python tests/test_core.py xyz 41.24 21.26 1.93 --white 94.810 100 107.305
python tests/test_core.py lab 60 20 35 --white 94.810 100 107.305
```

```python
from colorstimuli import lab_to_colorstimulus

stimulus = lab_to_colorstimulus([60, 20, 35], xyzw=[94.810, 100, 107.305])
print(stimulus.u_name)
```

The Python API defaults to white `[95.047, 100, 108.883]`, La=64, Yb=20 and average surround. Pass the web app's reference white explicitly when comparing results.
